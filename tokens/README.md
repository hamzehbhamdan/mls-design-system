# Tokens

`tokens.json` is the single source of truth, in [W3C Design Tokens Community Group](https://design-tokens.github.io/community-group/format/) format. Everything in `dist/` is generated from it plus `data/clubs.json`.

```bash
npm run build
```

## Structure

```
color.primitive.{neutral,red,navy,green,amber,cyan}.{0…1000}   raw ramps, no meaning
color.brand.{red,navy,white,black}                             the league marks
color.accent.{base,contrast,muted,emphasis}                    a SLOT, club themes override it
color.semantic.{light,dark}.*                                  role-based  ← reference these
font, fontWeight, fontSize, lineHeight, letterSpacing
space, radius, borderWidth, shadow
duration, easing, breakpoint, zIndex
geometry                                                       slash angle, crest clear space
```

Aliases use `{dot.path}` and are resolved at build time. A circular or unresolved alias throws rather than emitting a broken value.

## Naming

`--mls-` + the dot path with dots replaced by hyphens:

```
color.primitive.red.600   →  --mls-color-primitive-red-600
space.4                   →  --mls-space-4
easing.drive              →  --mls-easing-drive
```

Semantic tokens drop the scheme segment, because the scheme is expressed by the selector:

```
color.semantic.light.fg-muted  →  --mls-color-fg-muted   (under :root)
color.semantic.dark.fg-muted   →  --mls-color-fg-muted   (under [data-theme="dark"])
```

## Ramps

Generated by `scripts/gen_ramps.py` in OKLCH so steps are perceptually even, then pasted into `tokens.json`. Run `npm run ramps` to regenerate and see the contrast report. The script is the *derivation*; `tokens.json` is the *record*, so the committed values are stable and reviewable in a diff.

`red.600` and `navy.900` are pinned to the documented brand values rather than to computed steps.

## Adding a token

1. Add it to `tokens.json` with `$value`, and a `$description` if the reason is not obvious.
2. `npm run build`.
3. `npm run verify`.

It appears automatically in the CSS, SCSS, JS, TypeScript declarations, JSON and Tailwind preset. Do not add it to any of those by hand.

## What not to do

- Do not edit `dist/`. It is overwritten.
- Do not reference `color.brand.*` from a component. Use `color.accent.*` — otherwise you break all 30 club themes.
- Do not add a semantic token to only one scheme. Both, always.
